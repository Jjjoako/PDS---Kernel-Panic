# Trabajo Práctico PDS

Repositorio compartido para el TP de PDS.

## Contenido

- **`logo-ligneo/`** — Logos creados para la web.
- **`Página-Web/`** — Código de la web.
- **`Figma/`** — Etapas de diseño en Figma.

## Cómo trabajar en este repo

Antes de empezar a trabajar, siempre traer los últimos cambios:

```bash
git pull
```

Al terminar, guardar y subir:

```bash
git add .
git commit -m "Descripción de lo que hiciste"
git push
```
